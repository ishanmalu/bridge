Everything moves with you

Either way round

The Mac's trackpad drives the PC, and the PC's mouse drives the Mac. Push through the edge, or double-tap Right Option or Right Ctrl.

Clipboard and files

Text, images and copied files arrive the moment you switch. Files land in Downloads/Bridge.

Shortcuts that make sense

Cmd becomes Ctrl on the PC, so Cmd+C copies there too. The PC's Ctrl+C arrives on the Mac as Cmd+C.

Media keys, both ways

Play, pause, skip and volume act on whichever machine you're driving. Brightness stays put.

Grab to take back

Touch a machine's own mouse while it's being driven and it's yours again, instantly.

Wakes a sleeping PC

Switch to a PC that's asleep and Bridge sends Wake-on-LAN. Full-screen games keep the pointer.

Just your network

No server, no account, no cloud. The two machines talk directly to each other.

Tiny and quick

About 3 MB, written in Rust, living quietly in the menu bar or tray.

Your fingers already know it

Modifiers swap so muscle memory works on both machines.

Private by design

  • End-to-end encrypted (Noise protocol), keys pinned at pairing
  • Six-digit pairing via SPAKE2, three tries per code
  • Keystrokes leave only while you're driving the other machine
  • Nothing touches the internet. Every line on GitHub

Questions

Why does my Mac say it can't verify Bridge?

The beta isn't notarised by Apple yet. Open System Settings → Privacy & Security, scroll down and click Open Anyway. On Windows, SmartScreen does the same: choose More info → Run anyway.

How do I update it?

Bridge checks once a day and shows a banner when a new version is ready. Click it, then Install and relaunch. Every update is verified with a signing key built into the app, and your Mac keeps its permissions. (On 0.1.x? Download the new version once by hand; it's the first one with the updater.)

Does it work with an Intel Mac?

Yes. The Mac download runs on Apple silicon and Intel, macOS 11 or later.

Can it type into admin windows on the PC?

Yes, when Bridge runs as administrator. Turn on Start at login from Program Files and it starts elevated every time without a prompt. Windows' own UAC prompts and lock screen are off-limits to every app.

It won't connect. What now?

Both machines need to be on the same network. If they can't find each other, type the pairing code followed by the address the other machine shows. The menu's Open log shows what's happening.

What does it cost?

Nothing. It's free for personal, non-commercial use, with the source on GitHub.
